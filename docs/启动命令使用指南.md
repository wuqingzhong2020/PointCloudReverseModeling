# ReverseModeler 启动命令使用指南

本文使用 **Windows Git Bash**，示例直接填写程序和实际路径，不使用变量。命令窗口中的业务命令、脚本格式及 Python 用法另见 [命令框架与 Python 使用指南](命令框架与Python使用指南.md)。

## 1. 进入程序目录

先编译程序，然后在 Git Bash 中进入包含 `ReverseModeler.exe` 的目录：

```bash
cd /d/projectWQZ/PointCloudReverseModeling/output/vc143-cpp20/release
```

后续以 `./ReverseModeler.exe` 开头的命令均在此目录执行。若工程位置不同，请将示例路径替换为本机实际路径。

## 2. 常用用例：启动录制与回放

### 2.1 导入点云、设置输出目录并开始录制

在 Git Bash 中执行：

```bash
./ReverseModeler.exe --input_file "D:/projectWQZ/other-resource/cloud/reverse_modeling_result-20260922-08-17-37.pcd" --output_dir "D:/projectWQZ/other-resource/out" --record_file "D:/projectWQZ/other-resource/out/test1.py"
```

这条命令打开工作台，按以下顺序处理：

1. **开始录制**：创建 `D:/projectWQZ/other-resource/out/test1.py`，父目录不存在时自动创建。
2. **设置输出目录**：初始化 `D:/projectWQZ/other-resource/out/result.json`，此时 `export_success` 为 `false`。
3. **导入点云**：按 mm 导入指定 PCD，不自动重建。
4. **继续操作**：在界面中框选、截取、重建，或在软件命令窗口输入业务命令。每条成功执行的业务命令立即写入并刷新录制文件。
5. **完成交付**：模型生成后点击“导出并退出”，或在软件命令窗口输入 `project.export_and_exit`。成功交付后记录该命令，关闭录制文件，再退出程序。

`--record_file` 同时表示“开启录制”和“指定录制文件名”，不是执行这个文件。文件已存在时直接覆盖，不弹确认，命令窗口会显示：

```text
录制文件已存在，已覆盖：D:/projectWQZ/other-resource/out/test1.py
```

创建或写入录制文件失败时，会报告具体原因并停止后续启动操作。帮助、参数错误及执行失败的命令不会写入录制脚本。

即使参数在命令行中写成先导入、后录制，程序仍然先启动录制，因此成功的输出目录设置和点云导入也会写入脚本。例如，完成一次重建和交付后，脚本中会包含：

```text
project.set_output_dir "D:/projectWQZ/other-resource/out"
cloud.import "D:/projectWQZ/other-resource/cloud/reverse_modeling_result-20260922-08-17-37.pcd"
model.reconstruct --mirror false --end-tolerance 30
project.export_and_exit
```

这是录制内容示意；实际文件还包含注释以及本次执行的其他命令，路径分隔符和引用格式可能由录制器规范化。

### 2.2 执行已经录制的脚本

前一个实例退出后，在 Git Bash 中执行：

```bash
./ReverseModeler.exe -f "D:/projectWQZ/other-resource/out/test1.py"
```

程序打开工作台，按脚本顺序执行，并在命令窗口显示实际执行的命令及日志。

- 脚本已经包含 `project.set_output_dir` 和 `cloud.import` 时，无需再次传入 `--output_dir`、`--input_file`。
- 脚本记录了重建操作时，回放会重新建模；只有导入命令时，不会自动增加重建步骤。
- 脚本中的 `project.export_and_exit` 成功后，程序自动退出，后续脚本内容不再执行。没有这条命令时，脚本执行完毕后工作台保持打开。
- 未捕获错误会停止后续执行，已经成功完成的操作不会自动回滚。
- 回放使用脚本中保存的实际路径。需要改用其他输出目录时，修改脚本中的 `project.set_output_dir` 一行。

同一个输出目录在运行期间由该实例独占，因此请等前一个使用该目录的程序退出，再回放。

## 3. 启动参数说明

| 参数 | 作用 | 说明 |
|---|---|---|
| 无参数 | 打开工作台 | 不自动导入或执行命令 |
| `-h` / `--help` | 打印程序启动用法 | 输出到启动终端后退出，不打开 GUI，不创建或覆盖录制文件 |
| `--input_file 路径` | 自动导入 PCD 点云 | 默认 mm，不弹单位确认，不自动重建 |
| `--output_dir 目录` | 设置本次固定交付目录 | 初始化 `result.json`；模型就绪后可执行“导出并退出” |
| `--record_file 路径` | 开启录制并指定文件名 | 使用 `.py` 扩展名；已有文件直接覆盖并打印提醒 |
| `-c 命令 参数…` | 启动后执行一条命令 | 支持业务命令及完整 Python 语句；普通命令执行完毕后工作台保持打开 |
| `-f 脚本.py 参数…` | 启动后执行一个脚本 | 后续参数作为字符串传给脚本的 `sys.argv[1:]` |

三个路径选项均可独立使用，也可与 `-c` 或 `-f` 组合；一次启动选择 `-c`、`-f` 中的一种执行方式。

解析时先从全部启动参数中提取 **仅三个保留键**：`--input_file`、`--output_dir`、`--record_file`。它们支持 `--键 值` 和 `--键=值`，不可重复、不可缺值或为空。其他参数（如 `--spacing`、`--mirror`）保留给业务命令或脚本。

执行顺序为：**开启录制 → 初始化输出目录 → 导入点云 → 执行 `-c` 或 `-f`**，未指定的步骤跳过。任务在工作线程顺序执行，GUI 保持响应。

## 4. 其他可直接执行的示例

### 查看程序帮助或命令帮助

以下两条只打印启动帮助并退出：

```bash
./ReverseModeler.exe -h
./ReverseModeler.exe --help
```

以下命令打开工作台，在软件命令窗口查询 `cloud.import` 的用法：

```bash
./ReverseModeler.exe -c cloud.import --help
```

### 导入后立即重建，同时录制

```bash
./ReverseModeler.exe --input_file "D:/projectWQZ/other-resource/cloud/reverse_modeling_result-20260922-08-17-37.pcd" --output_dir "D:/projectWQZ/other-resource/out" --record_file "D:/projectWQZ/other-resource/out/test1.py" -c model.reconstruct --mirror false --end-tolerance 30
```

重建结束后工作台保持打开，可继续检查或修改。完成后在**软件命令窗口**执行以下命令，或点击“导出并退出”：

```text
project.export_and_exit
```

不要另外启动一个新的 EXE 来导出前一个窗口里的模型；各实例有各自的工程状态。

### 回放时重新录制

```bash
./ReverseModeler.exe --record_file "D:/projectWQZ/other-resource/out/test2.py" -f "D:/projectWQZ/other-resource/out/test1.py"
```

执行 `test1.py`，将实际成功执行的业务命令记录到 `test2.py`。`--record_file` 不能与本次 `-f` 指向同一个文件，避免启动录制时覆盖待执行的脚本。

### 执行 Python 语句

```bash
./ReverseModeler.exe -c "print('hello')"
```

程序打开工作台，在命令窗口输出 `hello`。带空格的完整 Python 语句应作为一个带引号的参数传入。

## 5. Git Bash 路径写法

建议统一使用 **正斜杠 `/`，并给路径加双引号**：

```text
"D:/projectWQZ/other-resource/out/test1.py"
```

不要直接使用未加引号的 Windows 反斜杠路径：

```text
D:\projectWQZ\other-resource\out\test1.py
```

Git Bash 会把未加引号的 `\` 当作转义符。上述路径会变成类似 `D:projectWQZother-resourceouttest1.py` 的字符串，程序收到的就不是预期的绝对路径，可能导致点云找不到、录制文件写到 EXE 所在目录。

中文、空格路径同样使用引号。相对路径按照**启动终端当前目录**解析，不自动以脚本目录为基准。若找不到录制文件，先检查命令窗口“开始录制”或“已覆盖”日志中的完整路径。

## 6. 导出结果

以上示例成功执行“导出并退出”后，固定交付文件位于：

```text
D:/projectWQZ/other-resource/out/reserveModel.step
D:/projectWQZ/other-resource/out/result.json
```

`result.json` 成功内容为：

```json
{
  "model_file": "reserveModel.step",
  "export_success": true
}
```

仅设置输出目录、导入、普通 STEP 导出或直接关闭窗口，都不会把 `export_success` 改为 `true`。请等待本次程序退出后再读取交付结果；导出失败时查看软件命令窗口的具体日志。
